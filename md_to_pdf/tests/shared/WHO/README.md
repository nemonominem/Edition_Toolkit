# tests/shared/WHO — Private article inputs

> **Gitignored.** All files in this directory match `**/WHO*` in `.gitignore`
> and are never committed to the repository.

## Files

```
WHO/
├── WHO_Compromission.md           Original article — extracted from source,
│                                  not edited directly after extraction.
├── WHO_Compromission.md.bak       Automatic backup written by md_harden --apply
│                                  before the original is overwritten.  Safe to delete
│                                  once the hardened version is validated.
├── WHO_Compromission_hardened.md  Hardened source — this is what gets converted
│                                  to PDF.  Apply layout divs here before conversion.
├── WHO_Compromission_review.md    Hardening review file — generated by md_harden
│                                  --review, edited by hand, consumed by --apply.
├── WHO_Compromission.json         Per-article sidecar: author, title, pub_name,
│                                  doc_type, and Typst typography overrides.
│                                  Auto-detected by md2pdf when adjacent to the .md;
│                                  use --meta here because the hardened stem differs.
├── WHO_Compromission_overrides.css  WeasyPrint visual overrides (font, spacing,
│                                  heading colours).  Passed via --custom.
└── images/                        Article images + pre-rendered Mermaid PNGs
    ├── *.png / *.jpg / *.webp     Referenced by relative path in the .md files.
    └── _mermaid_1.png             Pre-rendered by mmdc on first md2pdf run;
        _mermaid_2.png             reused on subsequent runs (not regenerated if
                                   the PNG already exists).
```

## How files are produced

### 1. Extraction

```bash
cd medium_to_md
python medium-to-md.py https://medium.com/… --disk
# → WHO_Compromission.md + images/
```

### 2. Hardening

```bash
# Generate review (--claude requires ANTHROPIC_API_KEY in environment)
python md_harden/md_harden.py \
  md_to_pdf/tests/shared/WHO/WHO_Compromission.md \
  --review --claude --style intelligence

# Edit WHO_Compromission_review.md — delete or change Treatment on unwanted suggestions

# Apply surviving suggestions
python md_harden/md_harden.py \
  md_to_pdf/tests/shared/WHO/WHO_Compromission.md \
  --style intelligence \
  --apply md_to_pdf/tests/shared/WHO/WHO_Compromission_review.md
# → writes WHO_Compromission_hardened.md
# → writes WHO_Compromission.md.bak
# → prints the md2pdf command to run next
```

### 3. Layout tweaks

Open `WHO_Compromission_hardened.md` and add `<div>` wrappers as needed before
conversion.  Common operations:

| What | Syntax |
|------|--------|
| One-column section | `<div class="single-column">…</div>` |
| New page | `<div class="page-break"></div>` |
| New page + one-column (Annexes, Further Reading) | page-break div then single-column div |

See [engines/typst/README.md](../../../engines/typst/README.md) for the full
reference.

### 4. Conversion

```bash
# Typst (recommended) — sidecar must be passed via --meta
md2pdf md_to_pdf/tests/shared/WHO/WHO_Compromission_hardened.md \
  --style intelligence \
  --meta md_to_pdf/tests/shared/WHO/WHO_Compromission.json \
  --compile
# → WHO_Compromission_hardened.typ  (written alongside the .md)
# → WHO_Compromission_hardened.pdf  (written alongside the .md)
# Move outputs to tests/typst/WHO/ when done.

# WeasyPrint (optional)
md2pdf md_to_pdf/tests/shared/WHO/WHO_Compromission_hardened.md \
  --engine weasyprint --css intelligence \
  --meta md_to_pdf/tests/shared/WHO/WHO_Compromission.json \
  --custom md_to_pdf/tests/shared/WHO/WHO_Compromission_overrides.css
```

### 5. Move engine outputs

After a successful conversion, move the `.typ` and `.pdf` to the engine output
folder so `shared/WHO/` stays clean:

```bash
mv md_to_pdf/tests/shared/WHO/WHO_Compromission_hardened.typ \
   md_to_pdf/tests/shared/WHO/WHO_Compromission_hardened.pdf \
   md_to_pdf/tests/typst/WHO/
```
